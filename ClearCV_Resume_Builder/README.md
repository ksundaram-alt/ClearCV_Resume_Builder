# ClearCV — Frontend Resume Builder

A responsive, frontend-only resume builder made with HTML, CSS and vanilla JavaScript.

## Pages (4 total)
1. `index.html` — Sign in / create account
2. `dashboard.html` — Resume dashboard
3. `builder.html` — Resume editor
4. `preview.html` — Resume preview and PDF printing

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Demo usage
- Select **Create an account** to register.
- Sign in with the same email and password.
- Fill in the resume editor and select **Save and preview**.
- Select **Download PDF** and choose **Save as PDF** in the browser print dialog.

## Important limitations
This is a frontend-only academic/demo project. Login credentials and resume data are stored in browser `localStorage`. This is not secure authentication and must not be used for real accounts or sensitive information. Data is limited to the browser/device and can be cleared with browser storage.
